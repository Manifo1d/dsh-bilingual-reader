# 双语文档

在 DSH 的常规对话里，将 Word（.docx）、PDF、TXT 或 Markdown 文件拖入输入框，单击文件名就能在右侧打开双语阅读，发送前即可预览。也可以直接点击已发送的文件引用或助手回复中的本地文档链接。右栏自动翻译，左边的对话可以继续输入和发送消息。在右栏的查看器菜单可切换回 DSH 原有的预览方式。

左侧的「双语文档」入口仍可独立打开文件。独立阅读时，顶部文件名可以切换最近打开的文档，旁边的加号用于打开新文件。

## 阅读与翻译

在原文或译文中拖选文字，对侧会随选区显示黄色高亮。相同的数字和术语可直接定位到字词，跨语言内容按对齐句子或段落定位，表格按单元格中的段落定位。清除选区后高亮随之消失。划选不会触发模型请求。

- 打开文档即自动开始全文翻译。重新打开部分完成的文档会从缺失处续译，主动取消后可点击「继续翻译」。模型漏译或批量格式出错时，阅读器会单独补译相应段落。每一页左原文、右译文，共用滚动条。关闭翻译可回到单页阅读。显示已有译文无需再次翻译。
- 点击页码可跳页，左侧的页面导航可以按标题定位。加减号缩放两栏，点击百分比恢复适合宽度。窄窗口中同一页的原文和译文上下排列。
- Word 阅读版式保留常用段落格式、标题、表格、嵌入的 PNG、JPEG、GIF 和 WebP 插图，并识别显式分页。较长且无分页符的文件按段落分成阅读页。复杂公式、浮动排版和脚注的复现有限。PDF 原文按实际页面渲染，译文按页重排。
- 「更多选项」包含翻译方向、翻译剩余段落和双语编辑。实时同步在编辑停顿后更新译文。回写原文可单独启用，回译后的段落可以撤销。修改保存在阅读器内。
- 下载按钮导出包含原文、译文和问答的 Markdown。

## 文档问答

在常规对话右栏，点击「在当前对话提问」会把文档引用放入当前输入框。划选文字后点「提问」，草稿会附上文件、页码和原句，写好问题后由你发送。图片框选仍使用文档问答，文字问答记录也可在「更多选项 → 文档问答」查看。

在独立阅读器中，点击底部「问问 DSH」可直接提问。划选原文或译文后，点击「提问」可以引用原句。点击「框选提问」可拖出矩形引用区域里的文字。框住 PDF 区域或 Word 插图时，输入框会预览即将发送的截图。问答内可以连续追问、查看引用、复制回答。Enter 发送，Shift+Enter 换行。点击右上角收起返回阅读。

截图问答需要支持图像输入的 DSH 模型。扫描 PDF 可直接框选页面截图提问。纯文字模型可对划选的原文、译文和图注提问。短文按全文提问。长文问答会选取标题、各页片段和与问题相关的段落，模型能看到的内容取决于当前问题。

## 本地数据和运行要求

文档在本机解析，通过 IndexedDB 按文件内容保存编辑、译文、问答和阅读页码。最近列表显示五份文档。翻译使用当前 DSH 模型，问答会发送问题、必要的文档片段、最近的对话上下文和输入框中预览的选区截图。输入文件上限 40 MB，PDF 最多读取前 80 页，依赖本机 Poppler。

在 DSH 的「插件 → 添加插件」中可填写本项目目录，安装并启用。若刚替换同名插件并提示令牌无效，退出并重新打开 DSH。项目内的 `client.js` 已构建，可直接安装。

开发时在项目目录运行 `npm install` 后用 `npm run build` 重建客户端，`npm test` 验证 DOM 交互和宿主接口。
